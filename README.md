# BlackLou Games

Portal de jogos gratuitos para navegador, com identidade visual preta e verde neon.

## Jogos publicados

- [Neon Snake](./games/neon-snake/index.html) — jogo de cobra com recorde salvo no navegador.
- [Memory Matrix](./games/memory-matrix/index.html) — jogo da memória com oito pares.
- [Click Rush](./games/click-rush/index.html) — desafio de reflexo com rodada de 20 segundos.
- [Catálogo de jogos](./games/index.html)

Os três jogos foram criados em HTML, CSS e JavaScript, sem dependências externas, e incluem controles adaptados para celular quando aplicável.
